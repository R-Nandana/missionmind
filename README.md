# MissionMind 🚀

**Evidence-Grounded Space Mission Anomaly & Knowledge Intelligence Platform**

MissionMind helps planetary scientists detect, explain, and cross-reference anomalous observations from the Mars 2020 / Perseverance rover's MEDA instrument. Every score is computed by code; the LLM only explains structured results and must cite its evidence.

## Architecture

```
┌──────────────┐      ┌──────────────────┐      ┌─────────────────────┐
│   React/Vite │─────▶│  Node/Express    │─────▶│  Python FastAPI     │
│   Frontend   │      │  Backend         │      │  Analysis Service   │
│  :5173       │      │  :3001           │      │  :8000              │
└──────────────┘      │  • Auth (JWT)    │      │  • Anomaly (z-score)│
                      │  • Observations  │      │  • Similarity       │
                      │  • MongoDB Atlas │      │  • RAG (BM25+vec)   │
                      └──────────────────┘      │  • LLM explanation  │
                                                └─────────────────────┘
```

## Quick Start

### Prerequisites
- Node.js 18+
- Python 3.10+
- MongoDB Atlas account (free tier)
- OpenAI API key (optional; enables generated explanations)

### 1. Clone and configure
```bash
cp .env.example .env
# Edit .env with your MongoDB URI and OpenAI key
```

### 2. Analysis Service (Python)
```bash
cd analysis-service
python -m venv venv
venv\Scripts\activate        # Windows
pip install -r requirements.txt

# Generate synthetic MEDA data and ingest documents
python scripts/generate_meda_data.py
python scripts/ingest_docs.py
python scripts/seed_events.py

# Start
uvicorn app.main:app --reload --port 8000
```

### 3. Backend (Node)
```bash
cd backend
npm install
npm run seed     # seed missions + instruments into MongoDB
npm run dev      # starts on :3001
```

### 4. Frontend (React)
```bash
cd frontend
npm install
npm run dev      # starts on :5173
```

### 5. Evaluation
```bash
cd evaluation
python scripts/eval_anomaly.py
python scripts/eval_retrieval.py
python scripts/eval_faithfulness.py
```

## Cloud Deployment (Render)

The root `render.yaml` defines three independently deployed services: the FastAPI analysis service, the Express API, and the React static site. To deploy, connect this GitHub repository to Render and create a Blueprint from the repository.

The Blueprint prompts for `MONGODB_URI`; enter the URI for a MongoDB database whose network access permits the Render API service. `JWT_SECRET` is generated by Render, and service URLs are wired automatically. `OPENAI_API_KEY` is optional; add it to the analysis service's environment to enable generated explanations. Without it, the analysis service returns its local evidence-based fallback.

The Render analysis service uses `requirements-render.txt` and BM25 retrieval to fit the free instance's memory limit. Local development keeps dense vector retrieval enabled through `requirements.txt`. Render's free web services sleep after 15 minutes without traffic, so the first request after idle may take about a minute to wake. For always-on use or dense embeddings, select a paid plan with more memory.

Deployment guide: <https://dashboard.render.com/blueprints/new?repo=https%3A%2F%2Fgithub.com%2FR-Nandana%2Fmissionmind>

## Scope
- **Mission**: Mars 2020 / Perseverance
- **Instrument**: MEDA (temperature + pressure)
- **Sols**: 1–100 (synthetic data modeled on real MEDA characteristics)
- **Documents**: 25 curated docs on MEDA, Mars atmosphere, Jezero Crater

## API Contract

`POST /analyze` — see [analysis-service/README.md](analysis-service/README.md)

## Evaluation Metrics
| Category   | Metrics                        |
|------------|--------------------------------|
| Anomaly    | Precision, Recall, F1          |
| Retrieval  | Precision@5, MRR               |
| RAG        | Faithfulness (claim→chunk map) |

## Non-negotiable Rules
1. All numerical scores computed by code, never by the LLM.
2. LLM must cite chunk IDs in its explanation.
3. If retrieval is weak → `"insufficient_evidence"`, never hallucinate.
4. Scores labeled "anomaly score", not "confidence".
